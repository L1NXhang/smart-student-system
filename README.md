# 智慧学工系统 (Smart Student Affairs System)

> 西华师范大学第28届电脑文化艺术节参赛作品 | 全国大学生计算机设计大赛备赛项目

## 项目简介

智慧学工系统是一套面向高校的综合性学生事务管理平台，聚合了学生日常管理、奖助服务、学业发展、安全管理、职业规划、沟通互动等核心功能模块，致力于打造响应更快、UI 更精美、适配更好的智慧校园体验。

### 为什么做这个项目

在日常校园生活中，学生与辅导员联系、部门发布活动、奖学金申请等功能分散在多个平台，导致需要频繁在多个软件之间切换，操作繁琐。因此，我们希望构建一个**统一聚合**的智慧学工系统，让师生在一个平台上高效完成所有学生事务。

## 功能模块

### 学生端 (17 页面)
- **首页工作台** — 奖学金概览、未读通知、待审核申请、近期活动
- **个人信息** — 证件照、学籍信息、家庭情况、紧急联系人、困难认定
- **奖助服务** — 奖学金申请、助学金申请、勤工助学
- **学业发展** — 成绩查询与绩点趋势、中期鉴定、第二课堂、获奖记录、违纪查询
- **职业规划** — 生涯测评、就业指导预约、就业信息
- **安全管理** — 晚归登记、外出报备、安全考试、异常上报
- **沟通互动** — 聊天室（实时通信）、公告通知、意见反馈、活动报名

### 管理端 (10 页面)
- **管理首页** — 学生总数、待审核统计、快捷操作
- **学生管理** — 学院/年级/班级筛选、批量导入、详情面板
- **申请审核** — 奖学金审核、信息变更审核
- **勤工助学管理** — 岗位发布与申请管理
- **学业管理** — 成绩导入
- **安全管理** — 晚归/外出审核、安全考试管理
- **公告管理** — 公告发布与编辑
- **活动管理** — 活动发布与报名管理

## 技术栈

### 前端
- **框架**: Vue 3 (Composition API + `<script setup>`)
- **构建工具**: Vite 8
- **UI 组件库**: Element Plus
- **状态管理**: Pinia
- **动画**: GSAP (ScrollTrigger, Timeline, 页面转场, 光标粒子)
- **路由**: Vue Router (Hash 模式)
- **HTTP**: Axios
- **实时通信**: Socket.io Client

### 后端
- **运行时**: Node.js 20
- **框架**: Express.js
- **ORM**: Sequelize + mysql2
- **数据库**: MySQL 8.0 (Docker)
- **认证**: JWT (JSON Web Token)
- **实时通信**: Socket.io
- **文件上传**: Multer

### 部署
- **服务器**: 腾讯云轻量应用服务器 (Ubuntu 22.04, 3.6GB RAM)
- **Web 服务**: Nginx (Docker Alpine)
- **容器化**: Docker
- **进程管理**: Node.js 原生集群

## 特色亮点

- **27 个完整页面** — 学生端 + 管理端全覆盖，功能齐全

## 本地开发

```bash
# 1. SSH 隧道连接远程数据库（如适用）
ssh -f -N -L 3306:localhost:3306 -i <your-key.pem> ubuntu@124.223.0.187

# 2. 启动后端
cd backend
cp .env.example .env  # 编辑数据库连接信息
npm install
npm run dev

# 3. 启动前端
cd frontend
npm install
npm run dev
```

前端运行在 `http://localhost:5173`，后端 API 运行在 `http://localhost:3000`。
